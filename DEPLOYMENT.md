# Deploy the research paper

1. Copy `docs/index.html` into the `docs/` folder of `jagtappranav2721-cpu/ML-Internship-FlyRank`.
2. Push the change to the `main` branch.
3. In GitHub, open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/docs`, then Save.
4. Wait for the Pages deployment to finish. Use the exact URL shown under Settings → Pages.
5. Open the URL in an incognito/private window and on a phone. Check all notebook links and the FlyRank credit link.
6. If the URL shown by GitHub differs from the candidate URL in `submission/paper_url.txt`, replace the file contents with the exact deployed URL. The file must contain one line only, starting with `https://`.
7. Commit and push `submission/paper_url.txt`.

Important: the URL in `submission/paper_url.txt` is the expected GitHub Pages project URL, not a claim that deployment has already been enabled or verified. Do not submit until GitHub Pages confirms the URL is live.
